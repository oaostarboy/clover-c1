# @clover/ui

Shared design system for the Clover C1 React interfaces — components, hooks,
utilities, fonts and overlays.

Vendored in-tree as an npm workspace. Consumers import it by name:

```ts
import { Button } from '@clover/ui/ui/components/button'
```

## Styles

```css
@import '@clover/ui/styles/fonts.css';
@import '@clover/ui/styles/globals.css';
```
