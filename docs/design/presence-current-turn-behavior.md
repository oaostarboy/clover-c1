# Bounded current-turn assessment contract (written before implementation)

## Admission and evidence
Only the existing opt-in private Telegram/desktop authenticated current human receipt may enter the ordinary compose seam. No slash commands, manual presence controls, tool text, foreign scope, historical scans, empty/oversized input or instruction/secret-shaped capsules. No language or emotion keyword is an eligibility condition. Manual `Carry thought:` remains compatible and needs no extraction call. Quiet hours, managed policy, Stop, generation/source revision and configured request/output limits remain authoritative.

One configured bounded provider call can return both tentative affect and one explicit unresolved question/interest. A maximum 3072-byte current capsule and 4096-byte strict duplicate-free JSON response apply. The schema is `affect` (null or finite valence/arousal/confidence plus `posture`) and `thought` (null or `summary`, `quote`, `confidence`, `owner`, `intent`, `source_context`). Allowed postures: ordinary, careful_brief, gentle, upbeat, reflective, clarify. Low confidence is ordinary. Calm, sadness, frustration, excitement, uncertainty and mixed affect are supported without claiming felt emotion or diagnosis. Negation, quotes, third-party emotion, sarcasm and ambiguity must encourage abstention, not keyword overrides.

Thoughts require confidence >= .7 and a summary/quote equal to the **entire** exact authenticated current source (<=512 UTF-8 bytes), not a first-person substring extracted from another speaker's words. The tentative schema must explicitly classify `owner=current_human`, `intent=unresolved_question|unresolved_interest`, and `source_context=direct`; third-party, unknown, task, resolved, quoted and reported classifications abstain. Structural quotation/code delimiters or blockquote lines independently withhold capture even if the model wrongly labels the whole source direct. These conservative checks sacrifice recall and do **not** prove natural-language speaker intent: wrongly labelled indirect speech without delimiters can still pass, and confidence is not calibrated. The host supplies the evidence owner, row ID, digest, revision and scope; model classifications cannot nominate credential/evidence owners, grant actions or change authority. No full source log or affect history is added. Existing thought TTL/caps/tombstones/claims/unknown ACK behavior remains.

## Adaptation and scheduling
A valid reading lives at most 120 seconds and influences only unsent current-user sidecar bytes. Cached prefix, history, toolsets and permissions remain unchanged. Stop, correction, new input, source change and revocation fence both admission and posture. `/emotions` renders the actual reading/posture or unknown, never invented neutral data.

Existing pending relevant thoughts take precedence over new extraction, including when their initiative gate is held/already offered: their later successful after-reply may get the event's single bounded connection decision, with the current topic included as labelled untrusted evidence. New captures cannot speak in their own turn. An unchanged topic must hold; later novel relevant context is necessary, not proof of semantic usefulness. Only enrolled after-reply/project-return events may initiate. No timer, sensor, research or new external permission is added.

Automatic captures require the connection decision to cite the exact later current source and overlap at least two of its novel lexical anchors. Existing explicit Carry thought records retain compatible source-citation behavior, but also need a different current source with at least two new anchors. A project view alone is not new conversation evidence. The reused Unicode-aware lexical relevance gate can miss paraphrases and cross-language connections; it is a conservative admission filter, not model understanding.

Both uses share the existing durable <=3/day/profile (or configured lower) reservation owner and <=1/event. A six-second current-assessment minimum interval is an additional process-local throttle, not a replacement for durable quota. Errors, rejection and timeout consume reservations. No retries, fallback, extra unaccounted calls or live enablement.

## Verification and quality limits
TDD uses the real ingress/compose/provider/status/state/after-reply path with explicitly SCRIPTED HTTP responses and blocked external network. Normative multilingual fixture labels require human review and are NOT measured model accuracy. Structural tests cover paraphrase, negation, quote, third party, sarcasm, ambiguity, mixed affect, calm/joy/sadness, English/French and abstention. Test outcomes measure plumbing, not classification accuracy or confidence calibration. An opt-in configured-provider evaluation harness is supplied but must not run live inference in this task. Inherited selected-account callback issue C1 belongs to the other builder; explicit configured fixtures here do not close it.

## Opt-in quality experiment (not executed against a live model here)

`python scripts/eval_presence_current_turn.py` only lists the normative fixture selection and reports zero provider calls. To run a separately authorized real-model experiment, an operator can pass `--execute-provider-calls --max-calls 1 --case sadness_fr`. This deliberately spends the current profile's already-enabled bounded presence quota; it never enables settings or chooses another account. Each invocation remains limited to at most three selected fixtures and the actual remaining daily quota. Gold labels are excluded from the inference prompt. Provider errors hold without retry. Results report actual schema-valid outputs and matches on the selected normative cases, never broad accuracy or calibration.

The live branch is exercised only with scripted HTTP in tests. Real emotional-quality evaluation remains unrun: measure false positives/negatives, abstention, multilingual/paraphrase errors and confidence calibration before making any broader claim. Human review must still judge whether source-backed extracted interests and later connections are useful; literal provenance is not semantic truth.
